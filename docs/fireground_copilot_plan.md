# 화재 현장 대응 Copilot 기획서

## 1. 프로젝트 개요

이 프로젝트는 소방관과 현장 지휘관이 화재 현장의 건물 정보, 화재 양상, 기상 조건을 입력하면 예상 피해 규모와 필요한 대응 자원을 빠르게 파악할 수 있도록 돕는 웹 기반 의사결정 보조 서비스다.

최종 방향은 두 가지 기능을 통합한 `화재 피해/자원 예측 + 대원 진입 안전 판단 Copilot`이다.

- 기능 1: 현장 상황 입력 기반 피해 규모 및 필요 인력/장비 예측
- 기능 2: 대원 생체 신호, SCBA, 유독/가연성 대기 센서 기반 진입/철수 판단

LLM은 위험 계산 자체를 담당하지 않고, 모델과 규칙 엔진이 산출한 결과를 현장 지휘관과 소방관이 이해하기 쉬운 한국어 설명으로 바꾸는 역할을 맡는다.

## 2. 문제 정의

화재 현장은 정보가 빠르게 바뀌고, 지휘관과 대원은 제한된 시간 안에 다음 판단을 내려야 한다. 특히 초기 대응 단계에서는 다음 정보가 빠르게 필요하다.

- 화재가 어느 정도 규모로 확산될 가능성이 있는지
- 현재 투입 인력과 장비가 충분한지
- 추가 구조대, 구급대, 사다리차, 배연 장비, 급수 지원이 필요한지
- 대원이 계속 진입해도 되는 상태인지
- 주변 대기 상태가 산소결핍, 폭발, 유독가스 위험 구간인지

이 서비스는 모델과 센서 데이터를 활용해 위 정보를 한 화면에서 제공하고, LLM을 통해 사람이 바로 이해할 수 있는 판단 보조 문장으로 보여준다.

## 3. 사용자

- 현장 지휘관: 전체 피해 규모, 추가 자원, 위험 요인, 지휘용 한 줄 요약이 필요하다.
- 진입 대원: 현재 대원 상태, 주변 대기 위험, 계속 진입 가능 여부가 필요하다.
- 상황실/훈련 담당자: 입력 조건별 위험 변화와 대응 자원 산정을 시뮬레이션하고 싶다.

## 4. 핵심 기능

### 4.1 기능 1: 피해 규모 및 필요 자원 예측

입력 항목:

- 건물 용도: 주거, 상업, 공장, 창고, 병원/요양시설 등
- 건축 구조: 철근콘크리트, 철골, 목조, 경량철골, 샌드위치 패널 등
- 층수, 지하층 여부, 연면적, 재실자 규모
- 화재 위치: 지상층, 상층부, 지하층, 옥상/외부
- 화염 규모, 연기 농도, 연소 확대 정도
- 기상 정보: 평균기온, 평균습도, 강수량, 최대풍속, 실효습도
- 신고 후 도착/대응 지연 시간
- 인접 건물 거리

출력 항목:

- 예상 피해 규모: 소규모, 중규모, 대규모, 매우 위험
- 예상 피해 영향 면적
- 필요 인력 규모
- 필요 장비: 펌프차, 물탱크차, 고가/굴절차, 구조대, 구급대, 배연 장비, RIT 등
- 주요 위험 요인
- 현장 지휘관용 요약 문장

현재 MVP는 이 기능만 구현한다.

### 4.2 기능 2: 대원 진입 안전 판단

입력 항목:

- 생체 신호: 심박수, HRV, 피부/심부 체온, 산소포화도, 호흡수
- 행동 상태: 넘어짐, 무동작, 방향 상실, 장시간 고열 노출
- SCBA: 공기 잔량, 소모 속도, 예상 퇴출 가능 시간
- 주변 대기: CO, HCN, O2, CO2, LEL, VOC, H2S, 연기/PM, 온도

출력 항목:

- 진입 가능, 주의 진입, 추가 진입 금지, 즉시 철수
- 위험 사유
- 다음 행동 권고
- 지휘관용 한 줄 알림

기능 2는 후속 단계에서 구현한다.

## 5. 시스템 구조

```text
웹 입력/센서 시뮬레이터
        ↓
피해 규모 예측 모델
        ↓
대원 안전 Risk Engine
        ↓
LLM Orchestrator
        ↓
사용자 친화적 설명 + 지휘관 알림
```

역할 분리:

- 피해 규모 예측 모델: 날씨, 건물, 화재 양상을 바탕으로 피해 규모를 산정한다.
- 안전 Risk Engine: 생체 신호, SCBA, 가스 센서 값을 기준으로 위험 규칙을 계산한다.
- LLM Orchestrator: 계산 결과를 소방 현장 언어로 요약하고 근거와 권고를 설명한다.
- 웹 UI: 입력, 결과, 위험 요인, 자원 추천을 시각적으로 보여준다.

## 6. 현재 데이터 및 MVP 모델 사용 방식

현재 프로젝트에는 `data/processed/강릉시_기상+산불_최종.csv` 데이터가 있다.

주요 컬럼:

- 평균기온, 최고기온, 최저기온
- 평균습도, 최저습도
- 강수량
- 평균풍속, 최대풍속
- 실효습도
- 산불발생여부, 산불발생건수
- 피해면적(ha)

현재 저장된 학습 모델 파일은 아직 없으므로, MVP 웹에서는 이 데이터의 타깃인 `피해면적(ha)` 분포를 기준으로 한 피해 규모 기준과 현장 보정 규칙을 사용한다.

MVP 기준:

- 소규모: 0.1ha 미만
- 중규모: 0.1ha 이상 1ha 미만
- 대규모: 1ha 이상 30ha 미만
- 매우 위험: 30ha 이상 또는 종합 위험도 85점 이상

이후 `models/` 폴더에 실제 학습 모델이 저장되면, MVP 규칙 엔진을 모델 추론 API로 교체한다.

## 7. LLM 출력 설계

LLM 프롬프트 방향:

```text
너는 소방 현장 지휘 보조 Copilot이다.
모델과 규칙 엔진이 계산한 결과를 바탕으로 위험도, 근거, 필요 자원을 설명한다.
최종 명령처럼 단정하지 말고, 현장 지휘관의 의사결정을 돕는 보조 의견으로 말한다.
출력은 현재 위험도, 핵심 근거, 필요 자원, 우선 조치로 구성한다.
```

예상 출력 예시:

```text
현재 입력 기준 피해 규모는 대규모로 추정됩니다.
강한 풍속, 낮은 실효습도, 샌드위치 패널 구조, 연소 확대 입력이 위험도를 높이고 있습니다.
초기 진압 인력만으로는 부족할 수 있어 구조대, 배연 장비, 추가 급수 지원을 함께 요청하는 것이 적절합니다.
```

## 8. MVP 화면 구성

1. 현장 입력 패널
   - 건물 정보
   - 화재 양상
   - 기상 조건

2. 예측 결과 패널
   - 피해 규모 등급
   - 종합 위험도
   - 예상 피해 영향 면적
   - 필요 인력/장비

3. 현장 상황 시각화
   - 건물 층수, 화점 위치, 연기/확산 강도
   - 자원 추천 요약

4. Copilot 설명 패널
   - 사용자 친화적 한국어 설명
   - 지휘관용 한 줄 알림
   - 주요 위험 요인

## 9. 개발 단계

### 1단계: 기능 1 MVP

- 정적 웹 UI 구현
- 현장 입력 폼 구현
- 피해 규모 예측 규칙 구현
- 필요 인력/장비 산정
- LLM 문장화 예시 출력

### 2단계: 실제 모델 연동

- `src/train_model.py`에 학습 로직 구현
- `models/`에 모델 저장
- 추론 API 또는 브라우저용 모델 포맷 연결
- 예측 결과와 MVP 규칙 비교

### 3단계: 기능 2 센서 판단

- 대원 생체 신호 입력/시뮬레이터 구현
- SCBA 잔량 및 퇴출 가능 시간 계산
- CO, HCN, O2, LEL 등 가스 위험 규칙 구현
- 진입/철수 판단 UI 구현

### 4단계: LLM 오케스트레이션

- 모델 결과 JSON 생성
- LLM 프롬프트 템플릿 작성
- 근거 기반 설명 생성
- 안전 문구 및 불확실성 표시

## 10. 안전 및 한계

이 서비스는 데모 및 의사결정 보조용이다. 실제 현장에서는 소방 지휘 체계, 표준작전절차, 현장 지휘관 판단, 장비 인증 기준, 기관별 안전 규정을 우선해야 한다.

LLM 출력은 최종 명령이 아니라 모델/센서 기반 설명이며, 위험도가 높은 상황에서는 보수적으로 경고하도록 설계한다.
