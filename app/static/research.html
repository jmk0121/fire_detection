    어떤 원리로 판단하나요?
    센서 구성과 간단한 프로토타입

    환경 노드

    고온용 열전대 여러 개 → 변환 모듈 → ESP32 → 서버. 연구 데이터의 고온층 온도는 열전대 배열에서 계산한 값입니다. 기존 실온 센서의 값을 그대로 대체할 수 없습니다.

    대원 노드

    IMU의 가속도로 걸음을 감지하고 자이로로 방향 변화를 누적합니다. 향후 UWB 거리 관측으로 누적 오차를 보정합니다. 기압은 층 변화 후보, 심박은 별도 생체 상태 정보로 둡니다.

    구조 노드

    상온 모형 보 + 변위 센서 + IMU → 휨과 진동 변화 기록. 이번 구현은 공개 실험의 변위만 판정에 사용합니다. 실제 건물은 구조형식·하중·센서 위치별 기준이 필요합니다.

    센서와 시각·단위 → 데이터 품질 확인 → 모듈별 추론 → 근거·결측·경보 이력 → 지휘 화면

    우선 상온 보행·모형으로 시연합니다. 통신 패킷에는 node_id, timestamp, sequence, unit, quality, battery를 포함하고, 3초 이상 새 패킷이 없으면 별도의 ‘통신 끊김’ 상태로 전환하는 구상입니다. 현재 화면은 저장 데이터 재생입니다.

    UWB 원리 실험 · 합성 기하 예제

    앵커 A(0,0), B(10,0), C(0,10) m에 대한 거리를 입력하면 세 원의 교점을 최소제곱으로 구합니다. 실제 UWB 데이터가 아니며 위 보행 성능에는 포함되지 않습니다.

    예제 위치: (3, 4) m. 계산 버튼으로 확인하세요.

    데이터와 선행연구

    출처를 따라가고, 직접 재현하기

    사용자 제공 선행연구: 「특수재난현장 진압대원의 안전을 위한 통합 지휘시스템에 관한 연구」(2015), 「소방대원 진압작전의 의사결정을 위한 붕괴예측시스템 개발」(2017). 센서 융합·위치 추적·구조 변화 감지를 참고했습니다. 붕괴 보고서의 −2.75는 가정값이므로 적용하지 않았습니다.

    센서 기반 위험 징후를 설명하는 통합 연구 도구 · 고등학생 탐구 프로젝트 위험을 이해하는 기술, 근거를 확인하는 화면.
